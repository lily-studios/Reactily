# `Reactily.useFocus`

Returns focus state for a GuiObject.

## Signature
```typescript
Reactily.useFocus(object: GuiObject): boolean
```
## Usage
```typescript
local isFocused = Reactily.useFocus(button)
```
## Works with

Pairs naturally with `createFocusGroup`, typed buttons, focus navigation.
