# `Reactily.CreateRef`

Compatibility alias for creating a Reactily ref. This export is present in the Reactily v2.1.0 package (API v1).

## Signature

```luau
Reactily.CreateRef
```

## Usage

```luau
local Ref = Reactily.CreateRef()
```

See the related API pages for parameter details and supported behavior. Check the v2.1.0 release source when integrating APIs whose callback or option types are important to your project.
