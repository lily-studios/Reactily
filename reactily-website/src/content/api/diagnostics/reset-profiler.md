# `Reactily.resetProfiler`

Clears all collected profiler data.

## Signature
```luau
Reactily.resetProfiler(): ()
```
## Usage
```luau
Reactily.resetProfiler()
```
## Works with

Pairs naturally with `setProfilingEnabled`, `getProfilerSnapshot`, `getSlowComponents`.
