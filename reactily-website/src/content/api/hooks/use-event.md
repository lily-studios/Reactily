# `Reactily.useEvent`

> Deprecated in Reactily 1.4. Use `Reactily.useEffectEvent` instead.

```luau
local handler = Reactily.useEvent(function()
	print(value)
end)
```

The alias is preserved throughout the Reactily 1.x line for compatibility.
