# `Reactily.useHover`

Returns hover state for a GuiObject.

## Signature
```luau
Reactily.useHover(object: GuiObject): boolean
```
## Usage
```luau
local isHovered = Reactily.useHover(button)
```
## Works with

Pairs naturally with `usePressed`, styles, interactive GuiObjects.
